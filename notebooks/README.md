# Student Score Prediction Using Linear Regression

## Project Description

This project uses Machine Learning to predict student scores based on study hours.

## Technology Used

- Python
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm

Linear Regression

## Project Features

- Train a Linear Regression model
- Predict student scores
- Evaluate model performance
- Accept study hours as user input

## Conclusion

This project demonstrates how Linear Regression can be used to predict student scores based on study hours.
